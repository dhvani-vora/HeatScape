# HeatScape Data

HeatScape is designed to use authoritative geospatial datasets.

## Planned datasets

### Landsat 8/9
Source: USGS / NASA
Purpose: Land Surface Temperature

### Sentinel-2
Source: Copernicus
Purpose: NDVI / vegetation

### ESA WorldCover
Source: European Space Agency
Purpose: Land cover and built-up classification

### WorldPop
Source: WorldPop
Purpose: Population density

### Greater Chennai Corporation / OpenStreetMap
Purpose: Roads, wards and water bodies

The sample_hotspots.json file contains demonstration data only.
