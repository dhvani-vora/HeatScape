# HeatScape Architecture

## Core Pipeline

Urban Data
↓
Data Processing
↓
Heat Hotspot Detection
↓
Cause Analysis
↓
Intervention Recommendation
↓
Impact + Cost Estimation
↓
Interactive Dashboard

## Planned Components

### Data Layer
Environmental and urban characteristics such as:
- Land Surface Temperature
- Vegetation
- Built-up density
- Impervious surfaces
- Road density
- Population density

### AI / Analytics Layer
- Heat risk scoring
- Hotspot identification
- Cause analysis
- Intervention recommendation
- Impact estimation

### Backend
Python/FastAPI API connecting the analytics layer to the frontend.

### Frontend
Interactive dashboard with:
- Urban heat map
- Hotspot selection
- Cause analysis
- Intervention recommendations
- Impact and cost estimates
