# HeatScape Data Sources

| Dataset | Provider | Purpose |
|---|---|---|
| Landsat 8/9 | USGS / NASA | Land Surface Temperature |
| Sentinel-2 | Copernicus | Vegetation / NDVI |
| ESA WorldCover | ESA | Land cover / built-up |
| WorldPop | WorldPop | Population density |
| GCC GIS | Greater Chennai Corporation | Local boundaries and infrastructure |
